## 🌟 Overview

Welcome to the engineering portfolio of **Arpit Avasarmol**, an AI Systems Engineer and researcher at **IIT Roorkee**. This portfolio is built with a high-performance **cyber obsidian glassmorphic design system**, featuring deep technical showcases, custom canvas visualizations, dynamic tab orchestration, and an easter-egg retro arcade game.

---

## ✨ Key Features

- ⚡ **Dynamic Dynamic Tab Orchestration**:
  - Live continuous marquee ticker in browser tab: `⚡ Arpit Avasarmol ✦ AI Systems Engineer ✦ IIT Roorkee ✦ Autonomous Systems & Diffusion...`
  - Animated pulsing SVG lightning favicon that adapts to system states.
- 🎨 **Real-Time ASCII Art Canvas**:
  - Custom canvas rendering of photographic ASCII matrix.
  - Hover-to-reveal photo transitions and grounded baseline HUD telemetry.
- 👾 **Pure Retro Pac-Man Arcade Engine**:
  - Full keyboard & touch-controlled Pac-Man game built directly into the CLI Palette (`Ctrl+K`).
  - Maze navigation, food dot collection, ghost AI, live scoreboards, and instant restart.
- 🔮 **Zero-Glow Dual Glitch Typography**:
  - "Arpit" with top white, center light-blue (`#38bdf8`), bottom white sandwich gradient.
  - "Avasarmol" with top white, center light-pink (`#f472b6`), bottom white sandwich gradient.
  - Non-blurry, ultra-sharp cyber jitter micro-shifts.
- 🎡 **Interactive Philosophy & Skill Wheel**:
  - Interactive wheel showcase displaying core research vectors across Generative Diffusion, Multi-Agent RAG, and Autonomous Systems.
- 💼 **Production Chronology & Selected Works**:
  - Unified editorial section tags (`01 / Philosophy`, `02 / Arsenal`, `03 / Chronology`, `04 / Selected Works`).
  - Deep-dive modals with architecture breakdowns and direct code repositories.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, Vanilla CSS Glassmorphism & Custom Keyframe FX
- **Visuals & Canvas**: HTML5 Canvas API (ASCII stream rendering)
- **Icons & UI**: Lucide React
- **Typography**: Syne, Space Grotesk, JetBrains Mono

## 🚀 Quick Start (Local Setup)

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/yashdesai05/arpit-portfolio.git

# 2. Navigate to project directory
cd arpit-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The portfolio will be running at `http://localhost:3000/`.

### Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
